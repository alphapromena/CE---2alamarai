# PWA icons

Generated by `scripts/generate-pwa-icons.mjs` — a zero-dep pure-Node encoder
(matches the D-032 posture: in-house, no new npm dependency, byte-deterministic
output). Regenerate after any brand-visual change:

```
pnpm generate:icons
```

Current artwork is a placeholder: solid accent-color square (`#4f46e5`) with a
centered white disc. Replace the render logic in the script — not these PNGs —
when the final brand mark is ready. All consumers (`public/manifest.json`,
`app/[locale]/layout.tsx` `metadata.icons`, `<link rel="apple-touch-icon">`
chain, iOS splash image) read directly from this directory.

Sizes emitted:

- `icon-{72,96,128,144,152,192,384,512}.png` — Android / desktop manifest (purpose: `any`)
- `icon-maskable-512.png` — Android adaptive icon, 80 % safe zone (purpose: `maskable`)
- `apple-touch-icon-{120,152,167,180}.png` — iOS home-screen icons
- `favicon-{16,32,48}.png` — browser tab favicons
- `apple-splash-1179-2556.png` — iPhone 14/15 Pro portrait launch image. Other
  device sizes are a documented follow-up in D-038.
- `icon.svg` — vector source for humans; not referenced by the manifest.
